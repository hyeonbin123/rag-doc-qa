# 질문 풀 3 (한국어 120문항): 출처와 라벨링 기록

`docs/experiments.md` v12부터 쓰는 한국어 질문 풀. 질문을 먼저 쓰고, 정답 문서는 그 뒤에 붙였음.

## 파일

- `eval/question_pool3_ko.txt`: 질문 120개, 받은 그대로 (한 줄에 한 문항, 고치지 않음). 문항 id `n001`~`n120`은 줄 번호
- `eval/pool3_labels.jsonl`: 문항마다 정답 페이지(`expected_source_paths`), 답이 있는 절의 앵커(`evidence`), 참고 답안, 키워드. 뺀 문항은 `dropped`에 이유를 적음
- `eval/build_pool3_sets.py`: 남긴 문항을 seed 20261004로 섞어 40문항씩 세 셋으로 나눔 (`tests/test_pool3_sets.py`가 커밋된 셋이 이 결과와 같은지 확인)
  - `eval/qa_dev2_ko.jsonl` (40): 튜닝용. v12에서 `qa_dev_ko`와 함께 설정을 고르는 데 씀
  - `eval/qa_test3a_ko.jsonl` (40): v12 테스트. 고른 설정에 한 번만 돌림
  - `eval/qa_test3b_ko.jsonl` (40): 다음 단계용으로 남겨 둠. v12에서는 열지 않음

## 누가 썼나

- **질문**: 2026-10-04, 별도의 LLM 에이전트가 썼음. 이 저장소와 FastAPI 문서를 보지 않은 상태에서 "FastAPI를 쓰는 개발자가 물을 만한 한국어 질문"을 쓴 것으로 전달받음 (이 조건은 전달받은 내용이고, 라벨을 붙인 쪽에서 확인할 방법은 없음). 원래 계획은 사람이 문서를 보기 전에 질문을 쓰는 것이었지만, 사용자가 질문 작성을 하지 않기로 해서 바꿈
- **라벨**: 2026-10-04, 이 단계를 맡은 Claude Code 에이전트가 붙였음. **라벨을 붙인 에이전트는 문서와 이 저장소, 이전 실험 결과를 모두 본 상태였음**
  - 코퍼스 스냅숏(FastAPI 저장소 커밋 `50113da16fec53b66b80d75e80a89296de4fa5a5`, DB에 적재된 277개 문서와 같은 커밋)의 Markdown 원문을 직접 읽고 grep으로 찾아 라벨을 적음
  - **어떤 검색 시스템도 돌리지 않았음** (dense·BM25·재정렬 모두). 정답 페이지는 사람이 문서를 찾듯 제목·절·본문을 읽고 정함
  - 정답 페이지는 그 페이지의 본문만으로 질문에 답할 수 있는 페이지를 모두 적음 (1개 98문항, 2개 20문항, 3개 2문항). 번역이 있는 페이지는 한국어 경로, 번역이 없는 페이지는 영어 경로로 적음. 검색 평가는 번역끼리 같은 페이지로 보므로 어느 쪽 경로로 적어도 결과는 같음
  - `evidence`의 앵커가 실제로 그 파일에 있는지 스크립트로 확인함 (120문항, 문제 0)
  - 참고 답안은 그 절의 내용으로 씀. 문서 원문을 옮기지 않고 요약함

## 뺀 문항

- **0개**. 120문항 모두 코퍼스로 답할 수 있다고 판단함
- 판단이 갈릴 수 있는 문항
  - `n115` (JSON을 보냈는데 422): 원인이 주어지지 않은 질문. 문서가 다루는 원인별로 세 페이지(엄격한 Content-Type 검사, 단일 타입 매개변수는 쿼리로 해석, 422 응답의 detail 보기)를 모두 정답으로 둠
  - `n069` (테스트용 DB 분리): 해당 페이지는 SQLModel 문서의 테스트 절로 안내만 함. 의존성 바꿔치기 페이지를 함께 정답으로 둠
- 영어 전용 페이지가 정답에 들어간 문항: `n054` 1개 (`reference/security/index.md`, API 키 도구 목록). 이 문항은 `qa_test3b_ko`에 들어감

## 한계

- 질문을 사람이 아니라 LLM이 썼으므로 실제 사용자 질문의 분포·말투와 다를 수 있음. 문서를 보지 않고 썼다는 점은 v7의 `qa_test2`와 같지만, 주제가 FastAPI 문서 목차를 따라가는 경향이 보임 (문항별 정답 페이지 142개 중 tutorial 86, advanced 39, how-to 8, deployment 5, 최상위 페이지 5, reference 1)
- 라벨을 붙인 에이전트가 이전 실험에서 어떤 질문이 실패했는지 알고 있었음. 정답 페이지는 검색 결과가 아니라 문서 내용으로만 정했지만, 이 지식이 라벨에 영향을 주지 않았다고 보장할 수는 없음
- 기존 셋과 주제가 겹치는 문항이 있음 (예: `n059` CORS와 `qa_test2_ko`의 k001). 질문 문장은 다름
